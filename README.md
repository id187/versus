# VERSUS

`dataset/rule.md`, `dataset/characters.json`를 원본 데이터로 사용하는 1:1 PvE 전투 게임입니다.

## 구성

- `dataset/`: 캐릭터 원본 데이터와 규칙 문서
- `versus.py`: CLI 전투 엔진
- `web_server.py`: 로컬 웹 게임 서버
- `web/`: 브라우저 UI
- `VERSUS.exe`: 웹판 실행기
- `launcher/`: `VERSUS.exe` 빌드용 C# 런처 소스
- `AGENTS.md`: 데이터 변경 후 패치 작업 기준

캐릭터나 규칙을 수정할 때는 `dataset/` 안의 파일을 고치면 됩니다. 이후 "패치해줘"라고 요청하면 `AGENTS.md` 기준으로 엔진, 웹 UI, 문서를 함께 맞춥니다.

## 필요 환경

- Windows 10/11
- Python 3.10 이상
- .NET 9 Desktop Runtime
- WebView2 Runtime

Windows 10/11에는 WebView2 Runtime이 대부분 기본 설치되어 있습니다. `VERSUS.exe`가 실행되지 않으면 Python과 .NET 9 Desktop Runtime 설치 여부를 먼저 확인하세요.

## 실행

기본 실행은 `VERSUS.exe`를 더블클릭하면 됩니다. 실행하면 로컬 서버가 켜지고 WebView2 기반의 별도 게임 창에서 화면이 열립니다.

이미 서버가 켜져 있다면 게임 창만 다시 열립니다.

기본 주소는 다음과 같습니다. 이 주소는 각 실행자의 컴퓨터 안에서만 접근되는 로컬 주소입니다.

```text
http://127.0.0.1:8765
```

PowerShell에서 직접 실행할 수도 있습니다.

```powershell
.\VERSUS.exe
```

포트를 바꾸고 싶다면:

```powershell
.\VERSUS.exe --port 8766
```

브라우저를 열지 않고 서버 시작만 검사하려면:

```powershell
.\VERSUS.exe --smoke-test
```

웹판은 기존 `versus.py` 전투 판정을 그대로 사용하고, 브라우저에서 캐릭터 선택, AI 성향 선택, 행동 선택, HP/MP 확인, 턴 로그를 진행합니다.

내부 화면은 HTML/CSS/JS로 만들어져 있지만, 기본 실행은 `VERSUS.exe`가 직접 소유한 WebView2 창을 사용하므로 주소창 없는 독립 앱처럼 동작합니다. WebView2 초기화에 실패하면 Edge/Chrome 앱 모드 창으로, 그것도 사용할 수 없으면 일반 브라우저로 열립니다.

웹 화면은 전투 상태와 캐릭터 JSON을 한 화면 HUD와 도감 화면에 맞춰 표시합니다.

## How To Play

`VERSUS`는 플레이어와 AI가 매 턴 행동을 하나씩 선택해 싸우는 1:1 턴제 전투 게임입니다. 상대의 HP를 먼저 0으로 만들면 승리합니다.

1. `전투`를 누릅니다.
2. 내 캐릭터, 상대 캐릭터, AI 성향을 고릅니다.
3. `전투 시작`을 누릅니다.
4. 매 턴 사용할 행동을 하나 선택합니다.
5. 전투 로그와 양쪽 상태를 보며 다음 행동을 고릅니다.

### 행동 종류

모든 캐릭터는 공통 행동 3개와 캐릭터별 액티브 스킬 4개를 사용합니다.

- `일반 공격`: 상대 / MP 0 / 위력 10 / 명중률 100 / 우선도 0
- `일반 방어`: 자신 / MP 0 / 위력 - / 명중률 - / 우선도 3 / `[방어]`
- `명상`: 자신 / MP 0 / 위력 - / 명중률 - / 우선도 0 / MP 15 회복
- `액티브 스킬`: 캐릭터마다 가진 전용 행동입니다. MP, 위력, 명중률, 우선도, 효과가 스킬마다 다릅니다.
- `패시브 스킬`: 직접 누르는 행동이 아니라 조건을 만족하면 자동으로 적용되는 캐릭터 고유 효과입니다.

스킬 정보는 `대상 / MP / 위력 / 명중률 / 우선도` 순서로 표시됩니다. 자세한 캐릭터별 효과는 게임 안의 `캐릭터` 화면에서 확인할 수 있습니다.

### MP와 턴

모든 캐릭터의 최대 MP는 100입니다. 전투 시작 시 MP는 30이고, 턴 종료 시 기본으로 MP를 10 회복합니다.

액티브 스킬은 MP를 소모합니다. 행동 선택 시점에 MP 소모량과 우선도가 확정되며, 행동이 빗나가거나 조건 검토에서 실패해도 이미 소모한 MP는 돌아오지 않습니다. MP를 소모하기 전에 실패한다고 명시된 효과로 실패한 경우에는 MP를 소모하지 않습니다.

행동 순서는 우선도가 높은 쪽이 먼저입니다. 우선도가 같으면 SPD를 기준으로 선공 확률을 계산합니다. 판정 과정은 내부에서 처리되고, 전투 로그에는 결과 중심으로 표시됩니다.

### 명중과 회피

명중률이 있는 행동은 먼저 스킬 자체의 명중률을 판정하고, 성공하면 대상의 회피를 판정합니다. 빗나가거나 회피된 행동은 피해와 명중 시 효과를 처리하지 않습니다.

명중 판정을 통과하고 조건 검토에서 실패하지 않은 공격 행동의 공격 피해는 최소 1입니다. 고정 피해는 공격 피해와 별도로 처리됩니다.

### 공통 키워드

`[방어]` 행동에 성공하면 그 턴에 입는 공격 피해를 경감합니다. 이 규칙은 `일반 방어`뿐 아니라 효과에 `자신이 이 턴에 입는 공격 피해를 경감` 문구가 포함된 캐릭터 전용 행동에도 적용됩니다.

| 연속 사용 횟수 | 피해 경감률 |
|---:|---:|
| 1회째 | 50% |
| 2회째 | 40% |
| 3회째 | 30% |
| 4회째 | 20% |
| 5회째 | 10% |
| 6회째 이후 | 0% |

피해를 실제로 입지 않아도 `[방어]` 행동에 성공하면 연속 사용 횟수가 증가합니다. `[방어]`가 아닌 행동이 실패하지 않고 행동 종료 시점에 도달하면 연속 사용 횟수는 초기화됩니다.

`[연격] X ~ Y`가 붙은 공격 행동은 명중률과 회피를 한 번만 판정한 뒤, 정해진 범위 안에서 타격 수를 결정합니다. 각 타격은 개별 공격 피해로 처리되며, 모든 타격이 끝난 뒤 명중 시 효과를 한 번 처리합니다.

전체 판정 순서와 세부 규칙은 `dataset/rule.md`를 기준으로 합니다.

## 콘솔판

```powershell
python .\versus.py
```

시스템 Python이 없고 Codex 번들 Python만 있는 경우:

```powershell
& "$env:USERPROFILE\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe" .\versus.py
```

## 콘솔 옵션

```powershell
python .\versus.py --player 1 --ai 2 --personality R --seed 1
```

- `--player`, `--ai`: 캐릭터 번호를 1부터 지정합니다.
- `--personality`: `R`, `C`, `D`, `M`, `G`, `E`, `J`, `A` 중 하나를 지정합니다.
- `--seed`: 같은 난수 결과를 재현합니다.
- `--auto`: 플레이어도 AI가 자동 선택합니다.
- `--max-turns`: 자동 전투의 최대 턴 수를 제한합니다.
- `--line-delay`: 출력 한 줄마다 기다릴 초를 지정합니다. 수동 플레이 기본값은 `0.08`입니다.
- `--fast`: 출력 지연 없이 빠르게 진행합니다.

천천히 읽으면서 플레이하고 싶다면:

```powershell
python .\versus.py --line-delay 0.15
```

## AI

AI는 가능한 행동마다 피해, 명중률, 비용, 처치 가능성, 방어 가치, 상태/버프/디버프 등을 점수화한 뒤 성향별로 선택합니다.

- `R`: 안정적인 기대값 위주
- `C`: 빠른 처치와 압박 선호
- `D`: 위험 회피와 생존 선호
- `M`: 가능한 행동 중 균등 무작위
- `G`: 최대 보상과 큰 변수 선호
- `E`: 자원, 중첩, 지속 효과 축적 선호
- `J`: 교란, 제한, 디버프 선호
- `A`: 이전 행동 기록을 이용한 대응 선호

`M` 이외의 성향도 최고점 행동 하나만 고정 선택하지 않고, 성향별 허용 범위 안의 상위 후보를 가중 랜덤으로 고릅니다. 같은 행동을 계속 반복하면 성향에 따라 감점이 붙으므로 전술 성향은 유지하면서도 약간의 심리전과 변덕이 생깁니다.

자동 테스트 예시:

```powershell
python .\versus.py --player 1 --ai 2 --personality R --auto --seed 1 --max-turns 3
```
